# ProspectMiner AI 🚀

A production-ready web application designed to streamline and automate prospecting workflows. Built with a strong emphasis on scalable architecture, client-side data security, and a seamless user experience.

## 🌟 Key Features
* **Full-Stack Architecture:** Clean separation of concerns between the frontend client and the backend server.
* **Production-Level Security:** Implemented robust data security measures to ensure the safe handling and flow of prospect information.
* **Modern UI:** Clean, responsive interface built with an emphasis on performance, leveraging modern CSS architecture.
* **Automated Deployment:** Configured for seamless continuous deployment and hosting via Render.

## 🛠️ Tech Stack
* **Frontend:** JavaScript, CSS (Tailwind CSS) 
* **Backend:** Node.js / Express
* **Infrastructure / Deployment:** Render

## 🚀 Installation & Local Setup

To run this project locally, you will need to start both the frontend and backend development servers.

**1. Clone the repository**
\`\`\`bash
git clone https://github.com/Rahul-biswal/ProspectMiner-AI.git
cd ProspectMiner-AI
\`\`\`

**2. Setup Backend**
\`\`\`bash
cd backend
npm install
npm start
\`\`\`

**3. Setup Frontend**
Open a new terminal window:
\`\`\`bash
cd frontend
npm install
npm run dev
\`\`\`
